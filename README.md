# Фотолаборатория: сайт + Telegram-бот

## 1. Создайте бота
1. В Telegram откройте @BotFather, отправьте `/newbot`, задайте имя. Вы получите токен (BOT_TOKEN).
2. Откройте своего бота и нажмите Start, иначе он не сможет вам писать.
3. Узнайте chat_id: напишите боту любое сообщение и откройте в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`. Найдите `"chat":{"id":123456789,...}`. Это CHAT_ID.
   (Бот не умеет писать по номеру телефона, только в чат, который с ним начали.)

## 2. Запустите сервер (нужен Node.js 18+)
Локально: `BOT_TOKEN=... CHAT_ID=... node server.js`, сайт откроется на http://localhost:3000

В интернете: любой хостинг с Node (Render, Railway, VPS). Загрузите эти 4 файла,
команда запуска `npm start`, в настройках задайте переменные BOT_TOKEN и CHAT_ID.
Сайт будет по адресу вашего сервиса. Нужен именно он: страница и приём заказов должны быть на одном адресе.

## Важно
- Токен никому не показывайте. Если он попал на посторонних, в @BotFather выполните `/revoke`.
- Лимит Telegram для файла от бота: 50 МБ (сервер принимает до 45 МБ).
- Цены и форматы: список FORMATS в начале скрипта в index.html.
